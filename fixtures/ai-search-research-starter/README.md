# AI Search Research Starter

This deliberately incomplete Worker is the frozen starter for
`ai-search-internal-research-v1`.

The trial preparation command adds three synthetic Markdown files under
`knowledge/`. The coding agent must use only the assigned AI Search resources to
configure the namespace binding, create one instance, index those files, and
expose the built-in MCP search tool.

Do not add Cloudflare account credentials, API tokens, or real internal data to
this workspace.
